# Comptage de mots

## Description
Application Java qui lit un fichier texte et compte
le nombre de mots par ligne et le nombre total de mots
dans le fichier.

## Technologies
- Java 21
- IntelliJ IDEA

## Structure du projet
- `Main.java` : Programme principal
- `texte.txt` : Fichier texte à analyser (à la racine du projet)

## Fonctionnalités
- Lire un fichier texte
- Compter les mots de chaque ligne
- Afficher le nombre de mots par ligne
- Afficher le nombre total de mots
